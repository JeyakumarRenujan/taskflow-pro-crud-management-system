# 🚀 TaskFlow Pro

A modern Full Stack CRUD Management System built with **React, Node.js, Express.js, and MySQL**.

## ✨ Features

- User Authentication (JWT)
- Create, Read, Update & Delete Tasks
- Responsive Dashboard
- Search & Filter Tasks
- Secure Backend APIs
- MySQL Database Integration

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Axios

## 📂 Project Structure

```
client/
server/
```

## 🚀 Getting Started

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
